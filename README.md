# 3d // Accela

3DAcc is a little Websit to show off a 3D modle and some text in a fancy way.
You can use it for a presentation, a background or else u can come up with.

## Usage

Just upload an 3D modle and move around with the Arrow Keys.
Open the settings with ESC.
